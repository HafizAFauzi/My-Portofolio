About me

Halo, saya Hafiz Ahmad Fauzi — seorang 2D & Pixel Artist sekaligus mahasiswa Teknologi Game di PENS. Saya fokus menciptakan aset UI game, environment, karakter, dan animasi, serta memiliki pemahaman di bidang Level Design dan Game Lore. Saat ini terbuka untuk peluang magang sebagai 2D/Pixel Artist di studio game profesional untuk terus berkembang bersama tim.
